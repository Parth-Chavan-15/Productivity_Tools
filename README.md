# 🛠️ Productivity Tools & Scripts

Welcome to my personal repository of automated scripts and utilities designed to streamline daily workflows, enhance Windows operations, and solve specific productivity bottlenecks.

## 🗂️ The Tools

Click on any of the folders above or the links below to view the dedicated documentation, source code, and setup instructions for each tool.

### 1. [🌗 Instant Theme Switcher](./DarkModeToggle)
A one-click batch/PowerShell utility that manipulates the Windows Registry and APIs to instantly toggle between Dark and Light mode without opening settings or restarting Explorer.

### 2. [📜 Bulk Certificate Generator & Splitter](./Certificate_Generator)
An end-to-end Python workflow designed to take a master PDF of generated certificates (like those from Canva) and automatically split, rename, and export them into hundreds of individual, perfectly named `.jpg` files based on a CSV data sheet.
